Contrast, measured — not asserted

A brand colour is not a text colour.

The semantic tokens in our system were chosen for fills and icons, then quietly reused for small labels. That is where accessibility breaks without anyone noticing: $danger and $info look decisive on a white card and fall under the body-text minimum the moment they have to carry words.

The meter below is live — it computes real WCAG 2.1 ratios in your browser. Each token is measured against both grounds, because that is the whole point: a fixed hex lands differently in light and dark, and a token that only passes in the theme you happened to design in is not a fix.

The accessibility sweep.

One pass across the salon operations tracking and dashboard screens, fixing contrast, theme parity and labelling together — because they are the same bug seen from three angles. A prototype hex that only ever ran in light mode is a contrast failure, a dark-mode failure, and usually sitting on an unlabelled control as well.

The sweep also turned up a defect nobody had filed: the anomalies panel's CSV export was missing its timezone dependency, so exported timestamps could carry a stale timezone. Reading a screen carefully for accessibility is also reading it carefully for correctness.

Name the action, not the state

A control labelled with the current state leaves you guessing what the tap will do.

"Open" — is the store open, or will this open it?
"Close store" when open, "Open store" when closed — a raised button with a matching accessibility label. State stays legible from the row tint, the opened-at line and the header counts.
Theme parity

The red scale inverts per mode, so a token picked in light mode silently flips meaning in dark.

backgroundColor="$red6" → resolves to #EF4444 in light; a white label on it fails.
A theme-stable red-600 hex for the destructive button, and theme-scaled pairs everywhere text is involved.
Icon-only controls

Refresh, sort, week navigation, back, close, staff bubble — tap targets with no accessible name.

<IconButton icon={RefreshCw} />
Every icon-only control carries an accessibilityLabel naming what it does.

A usability principle nobody enforces is just a preference.

A design review catches a problem once. A lint rule catches it on every author, in every file, forever — and its error message teaches the fix at the exact moment of the mistake. So the house style is not a document. It is 117 rules that fail the build.

196 components · 68 primitives · 3 platforms

One system, six apps, three platforms.

Admin, operator, owner, customer, public and marketing surfaces all draw from a single component package. Shipping React Native and web from one source means a design decision has to survive a touch target, a mouse pointer and a screen reader before it counts as done.

State is a token, not a colour someone picked

Fifteen request states and four priorities, each with a named token — so "escalated" reads the same in a list row, a chart segment and a push notification.

Twelve named curves, one driver per platform

Web gets CSS transitions, native gets Reanimated springs, and the bundler picks the driver — so a component animates correctly on both without a platform branch inside it. A useReducedMotion hook gates anything decorative.

4 roles · 1,605 lines · written before any screen

The design work that happens before the first screen.

For the field-service product, nothing was drawn until each role's day had been written end to end — what they are trying to finish, what they can see, what they are allowed to change, and where the handoff to the next role happens.

That is what kept the dispatcher's screen from becoming the owner's screen with buttons removed. The owner needs every lever. The dispatcher needs today's route and the three exceptions blocking it. Same data, genuinely different interfaces.

Colophon

This page is the sample.

Hand-written HTML and CSS, no framework and no build step. It sets its own type scale, ships light and dark as two designed states rather than one inverted, lays out with grid and gap instead of margin arithmetic, keeps every focus state visible, lets wide content scroll inside its own container rather than the page, and turns its load animation off when your system asks for reduced motion.

The contrast meter computes real WCAG ratios in your browser rather than quoting mine. If you do not trust the numbers in the case study above, read the luminance function.

Type

Monospace as the display face — the subject is rules and tokens, so the page speaks in that vernacular. Humanist sans for reading, held near 68 characters.

Colour

Cool neutrals biased toward the accent. The semantic colours are the contrast-corrected pairs the sweep produced, kept separate from the accent hue.
